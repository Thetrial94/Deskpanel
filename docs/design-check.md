# Проверка раскладки и управления

Полный экран музыки строится вокруг одного центра: выбранный компьютер, состояние, трек, исполнитель, воспроизведение и громкость. Карточка музыки в обзоре использует тот же порядок кнопок: предыдущий, пуск/пауза, следующий. На низких экранах второстепенные подписи сокращаются, доступ к полному плееру сохраняется нажатием на название трека.

Обзор всегда помещается в окно без вертикальной прокрутки. Часы закреплены сверху слева, погода под временем. Из каталога 13 модулей можно выбрать максимум пять. Длинные списки календаря, сессий и устройств остаются прокручиваемыми, чтобы записи не терялись.

## Порядок экранов

Открой Настройки → Порядок экранов. Перетаскивай строки за ручку ⠿ или нажимай кнопки вверх/вниз. На клавиатуре можно сфокусировать ручку и использовать стрелки вверх/вниз. При перетаскивании у края список прокручивается. Escape отменяет перенос.

Номера показывают порядок включённых экранов. Галочка включает экран; хотя бы один остаётся включённым. Изменения сразу применяются к нижней навигации, свайпам и автосмене, сохраняются в этом браузере после перезапуска. Порядок модулей внутри обзора настраивается отдельно.

## Повторяемая проверка

`npm run check:layout` запускает отдельный Chromium/Edge с чистым профилем и синтетическим сервером. Реальные аккаунты, ключи, музыка и команды компьютеру не используются. Нужен установленный Chromium/Edge; путь можно указать через `DESKPANEL_BROWSER`.

Проверяются 14 представлений: обзор, погода, музыка, Codex, Claude, три режима таймеров, подключения, компьютеры, пульт, календарь, дом и встреча. Размеры: 1122×504, 412×892, 800×360 и 360×640. Дополнительные сценарии: пауза, длинные заголовки, большое число записей, отсутствие связи и закрытый плеер.

Проверка ищет горизонтальное переполнение, пустые экраны, слишком маленькие кнопки, обрезанные карточки обзора и вертикальную прокрутку на экранах с фиксированным набором элементов. Списки календаря, агентов и дома допускают прокрутку. Дополнительно проверяются состояние паузы, громкость, выбор компьютера, неподвижность управления таймерами при смене вкладок, изменение порядка кнопками/мышью/касанием/клавиатурой и сохранение после перезагрузки.

Снимки экранов и JSON-отчёт сохраняются в `.runtime/design-audit/`. Этот каталог игнорируется Git. Для отдельного набора артефактов можно передать имя: `npm run check:layout -- review`.

Обычные проверки: `npm test`, `npm run check`, `git diff --check`.

## Лимиты Codex и Claude · 18 ноября 2026

Добавлены две компактные шкалы над списком чатов: остаток на 5 часов и на неделю с московским временем сброса. Общие лимиты аккаунта не повторяются в каждой карточке сессии. Цвет выделяет низкий остаток; для отсутствующих значений шкалы не рисуются, устаревание и прошедший сброс обозначены явно.

`npm run check:layout -- quotas-verified`: 161 сценарий, ошибок выполнения и нарушений раскладки нет. Размеры 1122×504, 412×892, 800×360, 360×640. Проверены оба провайдера, разные остатки, отсутствие данных, устаревание, ожидание обновления после сброса и отключённый компьютер; остальные экраны и действия также прошли проверку. Длинные списки сессий допускают прокрутку, обзор по-прежнему помещается в одно окно. Скриншоты и audit.json находятся локально в `.runtime/design-quotas-verified`.

`npm test -- --test-concurrency=1`: 107 тестов. Новый адаптер и API работающего сервера проверены на настоящем Codex: источник вернул недельное окно и не вернул пятичасовое. Настройка statusLine и живые лимиты Claude требуют обновления на его ПК, эта проверка на ноутбуке не выполнялась.
