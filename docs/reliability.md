# Постоянная работа DeskPanel

## Автозапуск на Windows

После установки зависимостей (`npm ci --ignore-scripts`) запусти `Enable-Autostart.cmd` из папки проекта. Он создаёт ярлык DeskPanel в автозагрузке **текущего пользователя** и запускает наблюдатель без отдельного окна. Права администратора не требуются. На этом ноутбуке автозапуск установлен отдельно от Git; на другом ПК его нужно включить этой же командой.

После перезагрузки сервер стартует при входе этого пользователя в Windows. До входа, во время сна или при выключенном компьютере сервер недоступен. Программа не меняет питание, настройки входа и сетевой адрес компьютера. Чтобы адрес телефона сохранялся, закрепи IP компьютера в настройках DHCP домашнего роутера; автоматический поиск нового IP пока не реализован.

Наблюдатель проверяет локальный `/api/health`, запускает сервер с доступом из локальной сети на порту 4317 и перезапускает собственный процесс после его завершения. Повторные запуски ограничены задержкой до 30 секунд. Если DeskPanel уже запущен вручную, второй сервер не создаётся: наблюдатель ждёт его остановки. Если порт занят другой программой, она остаётся нетронутой, статус — `port_busy`.

Статус и управление из PowerShell в папке проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\deskpanel.ps1 -Action Status
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\deskpanel.ps1 -Action Stop
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\deskpanel.ps1 -Action Start
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\deskpanel.ps1 -Action Uninstall
```

`Stop` останавливает наблюдатель и его собственный сервер, проверяя PID, родителя и путь процесса. Вручную запущенный сервер остаётся включённым. `Uninstall` удаляет только свой ярлык автозагрузки; уже работающий сервер остаётся включённым. Ярлык не переносится через Git и содержит абсолютный путь: перед переносом папки выполни `Stop` и `Uninstall` из старого расположения, затем запусти установку из нового.

Диагностика — `.runtime/service-status.json`, `.runtime/service.log`, `.runtime/supervisor-error.log`. Серверный лог ограничивается при перезапуске: около 1 МБ плюс одна предыдущая копия. Папка `.runtime` исключена из Git. Установка не регистрирует службу Windows и не создаёт задачу с правами администратора.

## Мост телевизора

Наблюдатель может держать запущенным и мост couch-tv для экрана «ТВ». Создай файл `.runtime/tv-bridge.json`:

```json
{"dir": "C:/Users/1/Documents/TV Android/couch-tv"}
```

Затем выполни `Stop` и `Start`. Мост запускается из `.venv` этой папки. Он слушает только `127.0.0.1:5400` (`BIND_HOST`) и перезапускается после сбоя с той же задержкой, что и сервер. Если мост уже запущен вручную, второй экземпляр не создаётся. `Status` показывает `TvBridgeState` и `TvBridgePid`. `Stop` останавливает и мост, проверив родителя и командную строку. Лог моста лежит в `.runtime/tv-bridge.log`. Без файла `tv-bridge.json` поведение прежнее.

## Потеря связи на телефоне

Открытая панель проверяет сервер каждые 5 секунд. При отключении Wi-Fi показывает ожидание сети, при недоступном сервере — автоматическое переподключение. Повторные проверки через 2, 4, 8 и максимум 15 секунд; зависший запрос прерывается через 4 секунды. Кнопка «Повторить», возвращение сети и открытие вкладки запускают проверку сразу.

После восстановления обновляются календарь, агенты, музыка, погода, показатели и пульт компьютера, умный дом. Если старый запрос ещё выполняется, новое чтение произойдёт сразу после его завершения. Привязка телефона и настройки сохраняются. Активный экран не меняется, локальные отсчёты продолжаются, несохранённые формы не сбрасываются. Плашка связи не сдвигает раскладку. Управляющие команды не ставятся в очередь и не повторяются при восстановлении; при неоднозначном исходе проверь состояние перед новым нажатием.

Работает, пока страница уже открыта. Если закрыть браузер или обновить страницу при выключенном сервере, браузер не сможет загрузить панель; понадобится открыть прежний адрес после запуска компьютера. Для офлайн-загрузки приложения потребуется HTTPS или отдельная Android-оболочка.

## Обновление через Git

Останови наблюдатель командой `Stop`, получи обновления через `git pull --ff-only`, выполни `npm ci --ignore-scripts`, затем `npm test` и `npm run check`. Запусти командой `Start`; ярлык автозагрузки остаётся установленным. Обнови панель на телефоне. Подробнее — [работа на двух компьютерах](multi-computer.md).
