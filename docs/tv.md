# Телевизор

Экран «ТВ» показывает, что идёт на телевизоре, и работает как пульт. Есть питание, громкость, стрелки, OK, «Назад», «Домой», пауза и плитки приложений. На обзоре можно включить модуль «Телевизор»: название передачи или приложения, сезон и серия, «Выключен».

## Как устроено

DeskPanel не подключается к ТВ сам. Он ходит в мост [couch-tv](https://github.com/Seagey/couch-tv) (`bridge/API.md`), который держит соединение с телевизором по протоколу Android TV Remote v2. При желании мост работает и через ADB.

```
телефон → DeskPanel /api/tv → мост couch-tv :5400 → Google TV / Android TV
```

- Адрес моста по умолчанию — `http://127.0.0.1:5400`. Другой адрес задаётся на `localhost:4317` → Настройки → Телевизор. Разрешены только локальные HTTP-адреса.
- `/api/tv`, как и остальные приватные API, требует привязки телефона.
- Сервер передаёт мосту только фиксированный набор команд:
  - кнопки из списка `TV_KEYS` в `server/tv.mjs`;
  - `power` on/off;
  - `volume` up/down/mute;
  - запуск приложения из списка, который вернул сам мост.

  Ввод текста, ссылки, установка приложений и снимки экрана через панель недоступны.
- Статусы на экране:
  - «Мост couch-tv не запущен»;
  - «ТВ не привязан к мосту»;
  - «ТВ не в сети» (кнопка включения при этом остаётся);
  - обычный экран пульта.

## Через хаб

Если телефон открывает панель с хаба, а мост работает на другом компьютере, хаб передаёт `/api/tv` DeskPanel'у того компьютера (`/api/tv/local`) по его привязке. Мост при этом остаётся доступен только со своего компьютера.

1. На компьютере с мостом обнови DeskPanel и перезапусти его.
2. На хабе обнови DeskPanel (`git pull`), перезапусти и выбери источник телевизора.
   - В браузере: `localhost:4317` → Настройки → Компьютеры → «Телевизор».
   - В консоли хаба: `Select-DeskPanelTv -Name 'ПК'`. Имя — как в `Get-DeskPanelComputers`.

По умолчанию источник — сам хаб. Статусы для этой схемы:
- «Телевизор не выбран»;
- «Компьютер с ТВ не в сети»;
- «Компьютер с ТВ не привязан».

## Первый запуск

1. В папке `couch-tv` укажи IP телевизора в `config.json`. Для TCL 65C745 это уже сделано: `192.168.0.124`.
2. Встань у телевизора и привяжи его один раз:
   `.venv\Scripts\python bridge\pair_tv.py living-room`. Затем введи шестизначный код с экрана ТВ.
3. Запусти мост: `.venv\Scripts\python bridge\server.py`.
4. Открой экран «ТВ» в DeskPanel.
5. Чтобы мост запускался вместе с DeskPanel и поднимался после сбоев, настрой [автозапуск моста](reliability.md#мост-телевизора).

Особенности Windows (проверено 25.11.2026 на TCL 65C745):
- В окружение моста нужен пакет `tzdata`: `.venv\Scripts\python -m pip install tzdata`. Без него мост падает на часовом поясе Europe/Moscow.
- Не используй `pair_tv.py --code`. На Windows его проверка `os.kill(pid, 0)` завершает ожидающую привязку. Вместо этого запиши код в файл `bridge\data\pair-code-living-room.txt`, пока первая команда ждёт.
- У моста нет пароля, поэтому запускай его только для этого компьютера: `set BIND_HOST=127.0.0.1`.

Без ADB мост не знает, какие приложения установлены. Тогда панель показывает только распространённые: YouTube, Netflix, Spotify, Twitch, Moonlight и настройки.

ADB (сетевая отладка на ТВ) нужен мосту только для «что сейчас идёт», списка установленных приложений и открытия по ссылкам. Кнопки, питание и громкость работают без него.
