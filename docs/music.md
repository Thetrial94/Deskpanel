# Яндекс Музыка RS в DeskPanel

DeskPanel управляет Windows-приложением SpolzerMod/yamusic-rs на компьютере, где работает локальный сервер. Телефон отправляет команды этому компьютеру; звук воспроизводится на нём.

## Возможности

- Предыдущий и следующий трек.
- Воспроизведение и пауза.
- Запуск или открытие плеера на компьютере.
- В расширенной сборке: реальное состояние воспроизведения, название трека, исполнитель и громкость 0–100%. Изменения из самого приложения также появляются на панели.

На телефоне открой экран «Музыка». При первом запуске выбери музыку в приложении на компьютере. В обычной версии кнопка подписана «Пуск / пауза»: состояние не угадывается. В расширенной сборке она показывает «Пауза», когда музыка играет, и «Играть», когда воспроизведение приостановлено.

## Установка и подключение

Путь по умолчанию: %LOCALAPPDATA%/Programs/yamusic-rs/yamusic-rs.exe.
Другой абсолютный путь можно задать через переменную DESKPANEL_MUSIC_EXE перед запуском сервера.

Для расширенного управления нужен клиент из workflow Build DeskPanel music client. Он собирается из закреплённой версии v1.0.2:
https://github.com/SpolzerMod/yamusic-rs/commit/04c757400595fdcd2b7d8b78d87e03e6d95ebeab

Изменения находятся в integrations/yamusic-rs/. Собранный клиент использует обычный вход и настройки Яндекс Музыки RS. Сохрани копию исходного exe перед заменой. Расширение включается аргументом --deskpanel; DeskPanel передаёт его при запуске плеера. Если запустить exe обычным ярлыком без аргумента, останется базовое управление.

Обновление клиента на обычный релиз upstream уберёт расширение: нужно заново собрать совместимую версию. Автоматическую замену на неизвестные версии DeskPanel не выполняет. Модифицированный клиент, как и исходный, распространяется под GPL-3.0-only.

## Как устроено

- MusicSource опрашивает сервер раз в секунду, только пока открыт экран музыки и вкладка видима.
- GET /api/music возвращает доступность плеера и его состояние.
- POST /api/music принимает одну из команд: launch, toggle, next, previous, volume. Для volume требуется целое value от 0 до 100.
- PowerShell-мост использует штатный Win32 API, проверяет путь процесса-владельца окна yamusic_rs_tray и отправляет сообщение только этому окну.
- Базовые команды используют WM_HOTKEY с ID 1/2/3. Открытие окна — WM_APP+2. Расширенная громкость — WM_APP+3.
- Сборка с аргументом --deskpanel раз в 500 мс атомарно записывает %LOCALAPPDATA%/DeskPanel/music-state.json. В файле только PID, время обновления, playback, volume и название/исполнитель.
- Сервер принимает состояние только от текущего процесса плеера и не старше 4 секунд. При потере обновлений возвращается неизвестное состояние, ползунок скрывается.
- Команды не повторяются автоматически после сетевого таймаута. Успешная отправка означает постановку в очередь; кнопка и громкость затем обновляются по фактическому состоянию приложения.

Файлы входа, токены и аккаунт DeskPanel не читает. Сервер принимает POST только с собственного Origin, проверяет Host, заголовок X-DeskPanel, JSON и размер тела. Произвольные пути и команды от телефона не принимаются.

Доступ к пульту есть у устройств домашней сети, открывших DeskPanel. Проверки Origin защищают от команд с посторонних сайтов, но не заменяют авторизацию устройств. Сервер не предназначен для выставления в интернет.

## Несколько компьютеров

Текущая реализация управляет только компьютером с сервером DeskPanel. Выбор между ноутбуком и стационарным ПК пока не реализован. Для него потребуются отдельный мост на каждом компьютере, сохранённый список устройств и явный выбор адресата команд. Панель на телефоне должна оставаться доступной при выключенном ноутбуке. Перенос воспроизведения между устройствами — отдельная функция.
