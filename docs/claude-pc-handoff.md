# Проверить уже настроенный Claude на стационарном ПК

Это задание выполняется на ПК, где установлен Claude. Общая панель и маршрутизация хаба опубликованы в ветке `codex/initial-panel`, коммит `6e1c282`. В общей ветке `server/adapters/claude.mjs` пока заглушка, всегда возвращающая `not_configured`. Пользователь сообщил, что настройка Claude уже выполнялась на ПК.

1. Проверь `git status` в существующей папке DeskPanel. Сохрани сделанные на ПК изменения до получения обновлений; не применяй reset/clean и не затирай работающую настройку. Проверь установленную версию Claude, существующие обработчики и локальный мост событий, читая только относящиеся к нему поля. Не печатай настройки с секретами или тексты чатов.
2. Выясни, есть ли уже локальная реализация адаптера и поступают ли реальные события. Если есть — используй её и объедини с новой маршрутизацией хаба через Git. Если есть только хуки, подключи их реальные события к `readClaudeStatus`. Не меняй данные Codex на ноутбуке.
3. Сохрани контракт: `readClaudeStatus()` возвращает `{id:'claude', name:'Claude', connection, sessions, updatedAt}`. Сессия содержит хешированный ID, название, статус, время обновления и, когда оно известно, время перехода статуса. Тексты чатов и аргументы инструментов отбрасываются. Список статусов и формат описаны в `docs/multi-computer.md` и существующих экранах агентов. Процесс Claude без событий не доказывает работу сессии.
4. Проверь реальные переходы: работа → вопрос → ответ → завершение, ожидание разрешения → решение, прерывание, устаревание. Сохрани другие пользовательские обработчики. Установку или изменение личных hooks согласуй в контексте этого ПК, если это ещё не разрешено там.
5. Выполни `npm test` и `npm run check`, опубликуй изменения адаптера и документацию в Git. Секреты, локальные события, настройки доверия и персональные файлы в Git не добавляются. Если одновременно идёт работа на ноутбуке, используй отдельную ветку и согласованное объединение, а не force push.
6. После обновления перезапусти DeskPanel. Проверь `/api/agents/local` на ПК: Claude должен иметь правдивый статус и реальные сессии. Не выводи их названия в логи проверки; достаточно состояния и количества.
7. Для связи с общей панелью получи код на ПК через localhost:4317 → Настройки. На доверенном телефоне, открыв панель хаба, добавь ПК по его локальному адресу и коду с ролью Claude. Дальше Кодекс на ноутбуке и Claude на ПК должны читаться одновременно, независимо от выбранного пульта и устройства музыки. Физическое отключение одного компьютера отключает только его агент и пульт.
