# Одна панель, независимые компьютеры

[Полная пошаговая установка на Windows Home через PowerShell, включая RustDesk](hub-powershell.md).

Мини-ПК с Windows — постоянно работающий хаб. Телефон открывает только адрес хаба. Ноутбук и стационарный ПК запускают собственный DeskPanel и передают хабу статусы и команды через отдельные привязки.

| Источник | Что от него зависит |
| --- | --- |
| Мини-ПК | Панель, календарь, умный дом, погода |
| Ноутбук | Codex и пульт ноутбука |
| Стационарный ПК | Claude и пульт ПК |
| Выбранное устройство музыки | Его Яндекс Музыка RS |

Оба агента видны одновременно при двух работающих компьютерах. Отключение одного компьютера очищает только его актуальные статусы и делает недоступным его пульт. Данные другого продолжают загружаться. Выбор пульта не меняет источники агентов, музыки, календаря и дома. Музыка направляется на явно выбранное устройство; автоматической отправки команды другому компьютеру нет.

## Установить хаб на мини-ПК

1. Установи Node.js 22.13+ и Git. Получи репозиторий и ветку `codex/initial-panel`, выполни `npm ci --ignore-scripts`. Подробности — [обновление](multi-computer.md).
2. Запусти `Setup-Hub.cmd`. Он включает существующий автозапуск DeskPanel при входе текущего пользователя в Windows, запускает сервер и печатает адреса для телефона. Если Windows спрашивает про сеть, разреши Node только в своей частной сети. Скрипт не создаёт правил брандмауэра и не меняет питание Windows.
3. На мини-ПК открой `http://localhost:4317` → Настройки. Подключи календарь и умный дом заново: прежние секреты остаются на ноутбуке и автоматически не копируются. Затем получи код доступа и введи его на телефоне, открыв адрес хаба.
4. В Fully задай этот адрес как Start URL. Ручной запуск Fully сохраняется. Адрес хаба желательно закрепить в DHCP роутера.

## Привязать ноутбук и ПК

В общей ветке есть адаптер Claude Code и сбор лимитов через statusLine. Обработчики устанавливаются и проверяются на самом ПК с Claude. Если настройка уже выполнялась там, сначала сохрани локальные изменения перед обновлением. [Задание для агента на ПК](claude-pc-handoff.md). Привязка сама по себе не устанавливает обработчики.

1. На каждом компьютере обнови DeskPanel до этой версии и перезапусти сервер. Для постоянной работы можно включить `Enable-Autostart.cmd`.
2. На подключаемом компьютере открой `http://localhost:4317` → Настройки → Показать код подключения. Код действует три минуты.
3. В настройках хаба выбери «Подключить компьютер»: название, локальный адрес DeskPanel с портом (один раз), код и агент. Ноутбук — Codex, ПК — Claude. Настройка с доверенного телефона также доступна.
4. В «Сохранить источники» проверь назначения Codex и Claude. Нажми сохранить. Теперь оба агента читаются независимо. Установка хуков Claude выполняется на самом ПК; привязка не устанавливает и не изменяет хуки.
5. На экранах «Компьютеры» и «Пульт» нажимай сохранённые кнопки устройств. На «Музыке» есть отдельные кнопки, где играть. Они не открывают чужую панель и не требуют заново вводить IP.

Старые браузерные ссылки на панели предлагаются как заготовки формы привязки. Сама ссылка не даёт доступа к агенту. При истечении привязки (30 дней) или смене IP повтори подключение: прежняя запись с тем же адресом обновляется. Имена кнопок не являются сетевым обнаружением; при смене адреса сначала удали прежнюю запись и привяжи новую. Закрепление адресов в роутере избегает этого.

## Доступ и ограничения

Ключи привязки хаба хранятся в существующем защищённом хранилище Windows (DPAPI текущего пользователя). В ответы `/api/nodes`, браузер и Git они не выдаются. Хаб может читать статусы и передавать команды на привязанный компьютер в течение срока привязки. Для удаления доверия открой «Компьютеры и агенты» → Отключить. Отдельный выбор источника не переносит токены календаря и дома.

Соединения внутри доверенной локальной сети используют HTTP. Для доступа через Интернет нужен отдельный защищённый транспорт; порты роутера открывать не нужно. Произвольные интернет-адреса, loopback, redirect и нестандартные пути в адресе устройства не принимаются.

Локальные API `/api/agents/local` и `/api/music/local` читают только собственный компьютер. Через них хабы не перенаправляют запросы по кругу. Команды не повторяются при ошибке и не направляются на запасной компьютер.

Работа «всегда» требует включённого мини-ПК, входа в Windows, доступной сети и внешних сервисов. Выключенный ПК не может играть музыку; выбери другой включённый компьютер. Открытие ссылки встречи из календаря запускается на хабе; перенос открытия на выбранный ПК пока не реализован.

## Проверка после установки

Сначала проверь оба агента и оба пульта, затем выключи DeskPanel на ноутбуке: Claude, ПК, календарь и дом должны остаться доступны. Включи ноутбук и повтори с ПК. Проверь отдельное переключение музыки и сохранение выбора пульта после обновления телефона. Реальное отключение трёх устройств проверяется после установки на мини-ПК; автоматические тесты моделируют эти состояния отдельно.
